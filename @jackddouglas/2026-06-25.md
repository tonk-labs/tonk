## Member names
`MemberName` has existed for each membership identity in a repo since membership was introduced, but there was never a mechanism to write anything meaningful to it. I now display the member's sigil alongside a default name (both derived deterministically from DID). On text hover, users can change their profile names the same way they'd change repo names.

`MemberName` is generated on each repo creation/join based on profile DID, but is overridden by a valid value in `ProfileName`. This ensures a user's name persists across repos in the local meta branch with `ProfileName`, but also syncs across users via the `main` content branch with `MemberName`.

## Templates all the way down
Today `core.yaml` is seeded into every repo at create time. It defines the binder, what the shell renders, and the top bar.

The "binder"/"workspace" is a tab switcher between `tonk:sheet` concepts.

The top bar is mainly for navigating between repos, editing repo/user profile name, and sharing.

Now that all the space rendering happens inside an iframe, there's an opportunity to further simplify by templating the binder model into just one of many UI configurations, and letting the user or agent modify the entire page at once. This provides more transparency and broadens the scope of malleability, but also brings more attention to what's stored in the space rather than the Tonk chrome surrounding it. Our Linear-esque issue tracker is one example where the binder/sheets model breaks down, because we just want to use the app, not fiddle with a UI that's built as if for spreadsheets.

The top bar is global so it needs to move outside the `tonk:shell` template into a separate iframe stacked over the content iframe. We'll need to pass events through the top frame so long as they don't interact with the the bar itself.

A repo will instead render a single editable root composition. When it's empty we draw a launchpad for users to connect their agent or choose from a template to get started. The existing sheets UI will be the first template.
