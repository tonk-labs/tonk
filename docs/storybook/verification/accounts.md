# Verification: accounts

Run this file with disposable account/access services, isolated browser
profiles and CLI homes, a PRF-capable virtual authenticator, and deterministic
fault checkpoints. After every mutation, inspect status from a fresh page or
process. Destructive rows require an unrelated profile/account plus owned,
joined, and local-only spaces to prove the boundary.
