# Verification: CLI, spaces, and browser runtime

Use a built CLI with isolated native state, deterministic fake remotes, and at
least two independent repository/account actors. TTY rows need a real
pseudoterminal. Browser rows use real Chrome with a clean profile and a coherent
deployed build. Record subject IDs and branch heads, not only display names.
