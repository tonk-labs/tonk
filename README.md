# Journal

A branch for journaling hypotheses, observations, and insights about this project.

## Guide

To participate, create a profile directory *(e.g. your github handle)* and add files named `YYYY-MM-DD.md`. Write in whatever format you like, but consider a few recommendations:

### Use headings

Headings give collaborators (and future you) something to link to when responding.

### Tag for feedback

Use `@gozala`-style mentions to ping people for feedback or credit. Include enough context so they know how to react when they read it.

### Quote what you reply to

Quote the thing you're responding to and link it, so readers get what they need without chasing links.

### Pull & push daily

Pull and push daily. You won't hit conflicts as long as you only edit files in your own profile directory — which is where most of your edits should be.

### Use pull requests for shared files

To edit this document or anything outside your profile directory, open a pull request.
