# ChatGPT compatibility adapter

Reusable hosting moved to [../hosted](../hosted/README.md), and standard MCP Apps
presentation moved to [../apps](../apps/ui.mjs). This directory retains the
optional OpenAI resource metadata adapter. The old npm `test:chatgpt`,
`start:chatgpt` and `build:chatgpt-assets` names remain compatibility aliases.

See the [compatibility matrix](../hosted/COMPATIBILITY.md) for tested SDK flows,
external-client acceptance gaps and unchanged deployment identities.
