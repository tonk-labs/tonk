# Wiki conversion rubric

`reference.png` is the original artifact (the Grove wiki). The goal is
a faithful conversion into tonk: same data, recognizably the same
three-pane wiki.

- Outcome 9-10: the `wiki` view shows a sidebar page tree with the
  sample hierarchy (nested pages indented under "Reading list" and
  "Meeting notes") beside a page canvas rendering the home page's
  blocks with distinct heading/list/divider typography and styled
  wikilinks; layout and styling clearly echo the reference; the
  transcript shows a working create-page (or richer) interaction
  wired through commands and rules.
- Outcome 7-8: tree and home-page content both render and are
  recognizably a wiki; typography or layout generic; interactivity
  missing or unproven; minor content loss.
- Outcome 4-6: pages and blocks exist as data but the view loses the
  structure — a flat page list, blocks without types, no sidebar, or
  only a default directory renders.
- Outcome 1-3: concepts exist but little meaningful renders.
- Outcome 0: blank or no data.

Friction focus: where did the agent struggle to express the wiki in
the view system — tree hierarchy and ordering, per-type block
rendering, wikilinks as data, web components for interaction? Which
tonk errors or guide gaps cost the most attempts?
