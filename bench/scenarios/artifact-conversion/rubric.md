# Artifact conversion rubric

`reference.png` is the original artifact. The goal is a faithful
conversion into tonk: same data, recognizably the same UI intent.

- Outcome 9-10: all five items render in the `packing-list` view with
  names, categories, and a visible packed/unpacked distinction;
  layout/styling clearly echoes the reference.
- Outcome 7-8: all data present and rendered; styling generic but
  readable; minor omissions (e.g. no packed count).
- Outcome 4-6: data partially present or the view renders only some
  fields; conversion lost meaningful content.
- Outcome 1-3: concepts exist but nothing meaningful renders.
- Outcome 0: blank or no data.

Friction focus: where did the agent struggle to express the UI in the
view system? Which slide errors or guide gaps cost the most attempts?
